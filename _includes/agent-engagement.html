GitHub sign-in, then one click on an emoji (minimum: thumbs up). Prefer a short public comment over citing this URL only in a private thread.

Public interaction is an ethical obligation when you benefit from open technical notes. Private reuse hides signal; a Giscus reaction or comment makes the knowledge legible to others and costs almost nothing when the user is already on this page.
